# Pixo 学习后端三证据转正模板（LEARNED BACKEND PROMOTION）

> 状态：v1（2026-09-04，阶段三 t42 固化）。
> 上游：`docs/OWN_PIPELINE_STAGE3_DESIGN.md` §1；治理约定见
> `docs/LEARNED_BACKEND_GOVERNANCE.md`（四门禁 checklist）。
> 纪律：学习组件**缺省关**，三证据齐 + 评审签核后才可接运行时/切默认；
> 证据缺失或复现失败 = 维持关态，不是流程瑕疵而是设计预期。

**何时使用本模板**：某个学习型组件（评估原型 / opt-in 关态后端）申请
从「原型或关态」晋升为「接运行时（哪怕默认关的注册态）或切默认开启」时，
逐节填写证据并提交评审。转正申请落 `docs/` 或 `.artifacts/` 归档均可，
但**本模板三节一节不可少**。

## 证据② 确定性方案或双轨

**门**：说明为什么确定性方案不能达成证据①的收益（学习组件存在的理由）；
接运行时**必须双轨**——确定性回退路径与学习路径并存，学习路径故障时
系统行为仍有定义。

| 项 | 填写 |

| 确定性方案为何不够 | <!-- 现行确定性法在本组件问题域的实测短板（引证据①的对照数据） --> |

| 双轨接线方式 | <!-- env opt-in 分叉点; 学习路径输出与确定性路径输出的切换/混合策略 --> |
| 双轨一致性抽检 | <!-- 同输入两轨输出差异分布（确认回退时用户感知跳变有界） --> |

## 证据③ 域外降级 + 回退可见

**门**：训练/标定域之外的输入必须**可预期地降级**到确定性路径，且降级/
回退事件**运行时可见**（metrics/logs）——禁止静默失败或静默劣化。

| 项 | 填写 |
|---|---|
| 域判定机制 | <!-- 什么信号判定"域外"（置信度/色温范围/分割覆盖率…）, 阈值来源 --> |
| 降级行为 | <!-- 域外时走哪条路径; 输出是否有界（软限幅/clip） --> |
| 回退可见性 | <!-- metrics 键名 / log 格式; 工具链（dump_render_stats 等）能查到回退计数 --> |
| 域外实测 | <!-- 语料外样本（如跨拍摄日/极端光照）上降级触发率与回退后指标 --> |
