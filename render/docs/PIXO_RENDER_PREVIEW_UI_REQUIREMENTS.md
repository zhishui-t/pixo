# pixo.render 预览/修图 UI 需求文档（定稿 v1.0）

> 状态：已与用户确认  
> 后续输入：架构师设计（更新 PIXO_RENDER_1S_PREVIEW_DESIGN.md）

---

## 1. 目标

在 Web UI 上像 Lightroom 一样查看 RAW 并实时调整参数：
- 打开 RAW 后显示预览图；
- 拖动曝光/白平衡/HSL 等滑块时预览实时变化；
- 调整结果可用于最终全质量渲染，也可输出 16-bit 预览给其他自动化修图模块继续计算。

## 2. 使用场景

- Web 前端展示与交互
- 后端 pixo.render Python + native C++ 内核
- 自动化修图模块通过 16-bit 预览接口获取高质量中间结果

## 3. 性能目标

| 场景 | 目标 |
|---|---|
| 首次打开 / 首次出图 | ≤1s |
| 拖动滑块实时更新 | ≤500ms |
| 实时更新分辨率 | 可用长边 512 快速预览 |
| 松手后精细预览 | 长边 2048~4096（按屏幕/DPR） |
| 放大 1:1 全尺寸查看 | 原图全尺寸，允许 1~3s，可分块渐进 |
| 最终全质量渲染 | 独立 4s 主线，参数复用 |

## 4. 分层预览策略

| 档位 | 分辨率 | 用途 | 目标 |
|---|---|---|---|
| 实时档 | 长边 512 | 拖动滑块 | ≤500ms |
| 精细档 | 长边 2048~4096（按屏幕） | 松手/查看 | ≤1s |
| 全尺寸档 | 原图全尺寸 | 1:1 查看 | 1~3s，可分块 |
| 导出档 | 原图全尺寸 | 最终输出 | 4s 主线 |

- 分辨率按**长边**定义，保持原始宽高比。
- 拖动时可用降采样预览，松手后刷新精细预览。

## 5. 全链路要求

预览必须支持 pixo.render 完整调整链（12 stage）：
- 曝光（EV/高光/阴影/白/黑）
- 白平衡（色温/色调）
- 影调曲线 / 对比度
- HSL / 分离色调
- 色彩校准 / 肤色保护
- 磨皮 / 风格化 / 精修

实时档允许必要降级（分辨率/低频 stage 降采样），但精细档与全尺寸档必须全链路生效。

## 6. 缓存与增量计算

- RAW 解码只做一次，缓存线性中间图。
- 拖动滑块时只重算受影响的 stage，避免全量 decode。
- 参数变化通过 Web 接口传给后端。

## 7. 接口要求

### 7.1 预览图接口（Web UI 显示）
- 返回 8-bit 图像（JPEG/WebP），用于浏览器显示。
- 支持参数：分辨率档位（512 / 2048 / 4096 / full）、调整参数。

### 7.2 16-bit 预览接口（自动化修图/后续计算）
- 返回 **16-bit RGB** 预览图（PNG 16-bit 或 TIFF 16-bit 或 raw 48bpp，由架构师定）。
- 用于其他模块继续计算，完成自动化修图。
- 内部渲染保持 16-bit 精度，输出编码可切换。

## 8. 质量门禁

- 1024 精细预览 vs 全质量：A/B 中位差 ≤2/255、p99 ≤10/255。
- 512 实时预览允许更宽松，主要用于手感。
- 16-bit 接口精度：与全质量计算差异需量化说明。

## 9. 最终渲染

- UI 调整参数可一键用于最终全质量导出。
- 最终渲染继续走 4s 主线，与预览分离。
