> 色相落点误差 = 染色主导像素 (w≥0.5 且结果 C≥0.02) 的结果 OKLCh 色相相对拨盘色相的角偏差。A 轨目标角经 UI_OKLCH_SPEC 表 B 锚点映射 (HSV 45°→81.3°); hsv 域 "V 保亮" 使降饱和染色的感知色相随量级/亮度漂移 (UI 规格 §2.2 已知非均匀性), oklch 域拨盘角即感知角。近白色度强加 = Y≥0.95 像素结果色度中位数: HSV 的 V 保亮在近白强加色度 (设计 §2.3 根治点), oklch 域 C_ref(L) 近白自然趋 0; 其落点误差集中于 C 很小的近白 clip 旋转 (内核已文档化的 M-O2 cusp 近似), 感知量级见色度列。

> 误伤 p95 的机理注: 掩码是余弦软窗无硬截止, 色相平移在掩码尾部 (m≈0.05) 仍有 ~0.5° 旋转 —— oklch 轨对彩度像素按感知角均匀旋转 (中性保护只压 C<0.02), hsv 轨的 hue_shift 另受 protect=S 阻尼, 故 hsv 尾部更小; 两者均 ≪ JND (ΔE2000 ≈ 1.0), 由 p95 闸门的 JND 地板口径覆盖。

## 结论 (中位数 / p95 不劣于判定)

- **意图 1 (+10 橙饱和)**: 扇区内实现强度 B/A 中位数 0.82 → 更弱 (A 1.264 / B 1.033, 量级对照非闸门 —— 同数值在两域的感知强度天然不同: HSV S 随 V 缩放且饱和无中性保护, OKLCh C 感知比例 + 中性保护; 色相角非均匀, 绿区压缩最狠 HSV 30° ≈ OKLCh 9°); 扇区外误伤 B/A — → **不劣于(小值)** (A 0.000 / B 0.000)。
- **意图 2 (+10° 绿色相)**: 扇区内实现强度 B/A 中位数 6.42 → 更强 (A 0.240 / B 1.538, 量级对照非闸门 —— 同数值在两域的感知强度天然不同: HSV S 随 V 缩放且饱和无中性保护, OKLCh C 感知比例 + 中性保护; 色相角非均匀, 绿区压缩最狠 HSV 30° ≈ OKLCh 9°); 扇区外误伤 B/A — → **不劣于(小值)** (A 0.000 / B 0.000)。
- **意图 3 (高光暖移)**: 色相落点误差中位数 B/A 0.40 → **不劣于** (A 11.27° / B 4.48°), p95 B/A 0.45 → **不劣于** (A 48.78° / B 21.81°); 近白色度强加中位数 B/A 0.15 → **不劣于** (A 0.0756 / B 0.0115)。
- **总体 (不劣于闸门 = 误伤 median/p95 ×2 + 落点误差 median/p95 + 近白色度)**: 全部通过 → oklch 域新内核不劣于 hsv 域旧内核。
