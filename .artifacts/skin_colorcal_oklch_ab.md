差异分解（同参数双意图 × 72 图 × 3 轨: hsv-native / hsv-python（禁 native）/ oklch-python）;
r10 复跑（OKLab 掩码重拟合联动 skin_protect 足迹，color_cal 算术未动）:

| 分解项 | portrait_card 意图 | strong_protect 意图 | 说明 |
|---|---:|---:|---|
| 算术差 ΔE(hsv-native, hsv-python) max | **0.0000** | **0.0000** | native 与 Python float 逐式等价 → **复合差 100% 来自掩码域** |
| 复合差 ΔE(A,B) median / p95 | 0.0000 / 1.1447 | 0.0000 / 2.8865 | 中位不可感知；p95 尾部为两轨足迹差带（修前 0.034 / 2.53——B 足迹变大后 XOR 带内进入更多有实差的色度肤像素，属足迹差带口径，非闸门） |
| 非肤区校正 cross med / p95 | 0.0000 / 0.0081 | 0.0000 / 0.0203 | **不劣于(小值)** —— 非肤区两轨行为逐位等价 |

### 2.2 性能成本（512px 全图）

| 轨 | native F32 | 纯 Python float | 汇总 |
|---|---:|---:|---:|
| 本轮复跑 median | 9.2 ms | 24.4 ms | **2.6×** |
| r9 首测（存档对照） | 8.5 ms | 131.1 ms | ≈15× |

计时两轮差异显著（24 vs 131 ms，color_cal 算术未动），疑为测量环境/首载
因素；方向性结论不变（Python 路径慢于 native 且随分辨率线性放大，
4096px export 外推需按上界 15× 预算）。**性能预算裁决权在队长/dev-2。**

### 2.3 colorcal 结论

**输出质量不劣于**（非肤区逐位等价；复合差 median 0.0000；算术零差 →
差异纯为掩码足迹）、肤区残留 B/A 改善至 1.06（入带）。**性能劣于**
（Python 路径 2.6×~15×，量级待统一测量口径）—— go/no-go 卡在性能预算：
oklch 域旁路 native 是当前架构的必然代价，除非 native 内核扩 OKLab 椭圆
或接受 auto 闭环变慢。
