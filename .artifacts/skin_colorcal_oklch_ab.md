## 1. skin 掩码域：cv2-Lab 椭圆（A/hsv 轨）vs OKLab 椭圆（B/oklch 轨）

### 1.1 掩码足迹（n=72）

| 指标 | A: Lab 椭圆 | B: OKLab 椭圆 | 判定 |
|---|---:|---:|---|

| IoU median / p10 / min | 0.768 | 0.512 | 0.137 | 足迹中等重合，尾部图分歧大 |
| Dice median | 0.869 | | |
| B 显著缩水（covA≥5% 且 covB<50%A） | — | **5/72（7%）** | 极端: portrait_tele 0.070→**0.009**、high_contrast 0.370→0.077 |

### 1.2 门控行为分叉（磨皮 wants 占比门限）

| 门限 | 分叉图数 | 说明 |
|---|---:|---|
| portrait 0.5% | **0/72** | 两轨门控结论一致 |
| 无 scene 3% | **2/72（2.8%）** | 同一张图（golden_portrait_tele = X1_DSC_0466）: A 6.99% 过门 → 磨皮；B 0.91% 不过门 → **整段直通**（欠磨皮，非误磨） |

### 1.3 磨皮意图（strength=0.5）分区 ΔE2000

| 分区 | A 轨作用 | B 轨作用 | 判定 |
|---|---:|---:|---|
| 双肤区效果强度（有磨皮作用图） | median 0.528 | median 0.493 | B/A 0.935 → 量级对照**接近对齐带 [0.9,1.1]** |
| 单轨带（A≥0.5 XOR B≥0.5） | A 侧 median 0.287 / p95 0.673 | B 侧 median 0.0 | B 足迹 ⊂ A 足迹为主 → 差异表现为 A 独有作用带（域几何差异，非闸门） |
| 双非肤误伤 | median 0.0 / p95 0.0 | median 0.0 / p95 0.0 | **不劣于(小值)** |
| 真值精检/召回（合成人像 2，洁净肤色） | P=1.000 / R=1.000 | P≈1.000 / R≈1.000 | 洁净肤色两椭圆等价；分歧集中在真实 RAW 的边界肤色 |

### 1.4 skin 结论

**伤害类不劣于**（双非肤误伤 0/0；B 足迹更紧只会少磨不会多磨），
**实现强度不劣于**（双肤区 B/A 0.935 入对齐带）。
风险面为**足迹域几何差异的行为分叉**：7% 图覆盖腰斩、2.8% 图触发 3% 门控
分叉（B 直通=欠磨皮）。方向上是「欠作用」而非「误作用」——与拟合报告
（fit_skin_oklch: OKLab 椭圆召回 0.83 / 误报更低）一致。

## 2. colorcal 双轨：native F32+Lab 掩码（A/hsv）vs 纯 Python float+OKLab 掩码（B/oklch）

差异分解（同参数双意图 × 72 图 × 3 轨: hsv-native / hsv-python（禁 native）/ oklch-python）:

| 分解项 | portrait_card 意图 | strong_protect 意图 | 说明 |
|---|---:|---:|---|
| 算术差 ΔE(hsv-native, hsv-python) median / max | **0.000 / 0.000** | **0.000 / 0.000** | native 与 Python float 逐式等价（test_native_colorcal 同口径）→ **复合差 100% 来自掩码域** |
| 复合差 ΔE(A,B) median / p95 | 0.000 / 0.034 | 0.000 / 0.088 | 中位不可感知 |

### 2.1 分区对照

| 分区 | portrait_card | strong_protect | 判定 |
|---|---:|---:|---|
| 单轨保护带（XOR≥0.5）ΔE median / p95 | 0.279 / 1.022 | 0.720 / 2.53 | 保护足迹差异带（skin_protect 越强差异越大；≈JND~2.5×JND） |
| 双非肤区 ΔE median / p95 | 0.000 / 0.000 | 0.000 / 0.000 | **不劣于(小值)** —— 非肤区两轨行为逐位等价 |
| 肤区校正残留（effect in 双肤区） A / B median | 0.629 / 0.695（B/A **1.106**） | 0.315 / 0.335（B/A 1.063） | B 掩码更紧 → 保护抑制略少、更多校正进入 A 认定的肤区；card 口径恰在 1.1 线上，strong 口径达标 —— **边缘，记观察项** |
| 非肤区校正 A / B median | 0.6204 / 0.6217 | 1.0359 / 1.0391 | 全局校正强度两轨一致（掩码只影响肤保护） |

### 2.2 性能成本（512px 全图，各 3 次计时取 median）

| 轨 | portrait_card | strong_protect | 汇总 |
|---|---:|---:|---:|
| A: native F32 | 8.6 ms | 8.5 ms | **8.5 ms** |
| B: 纯 Python float | 131.3 ms | 130.6 ms | **131.1 ms** |
| **B/A** | **15.3×** | **15.5×** | **≈15×** |

外推（逐像素线性）: 2048px 预览 ≈ 2.1 s/图；4096px export ≈ **8.4 s/图**
（auto 闭环逐轮都过 colorcal → 收敛轮数 × 8.4s 的交互成本）。

### 2.3 colorcal 结论

**输出质量不劣于**（非肤区逐位等价；复合差 median 0.000；算术零差 →
差异纯为掩码足迹），**性能劣于（≈15×，且随分辨率线性放大）**。
肤区校正残留 B/A 1.106（card 口径）恰在闸门线上，记观察项。
切换（若下轮 go）的决策权重完全在性能预算：oklch 域旁路 native 是
当前架构的必然代价（native 内核内嵌 Lab 域椭圆常数，域不匹配），
除非 native 内核扩 OKLab 椭圆或接受 15× 成本。
